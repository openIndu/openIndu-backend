# Security Policy

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting feature for this
repository. Do not disclose suspected vulnerabilities, credentials, tokens,
or exploit details in a public issue.

Include affected versions, reproduction steps, impact, and any suggested
mitigation. The maintainers will acknowledge the report and coordinate a fix
and disclosure timeline through the private report.

## Supported version

Security fixes target the latest release and the current `main` branch.
